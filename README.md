# QIEI facial-expression analysis

## Layout

- `implementation/` — pipeline source code, dataset copy, models, experiment results, and runtime logs.
- `docs/research/` — architecture, implementation, and research notes.
- `docs/project/` — experiment checklist and project assumptions.
- `docs/provenance/` — extraction trace.
- `data/raw/` — original dataset archive.
- `metadata/` — extracted concepts, notation, and summary metadata.
- `tools/` — standalone helper utilities.

Generated Python bytecode and new runtime logs are excluded by `.gitignore`.
